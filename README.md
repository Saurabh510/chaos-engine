# Chaos Engine — The Rules Are the Fractal

A complete, self-contained browser game. You are a particle trapped inside a
fractal — because the *rules of movement* are fractal.

You have exactly one movement operation:

```
P -> P + 0.5 * (Ai - P)
```

Every jump travels exactly halfway toward one of three fixed attractors.
There is no joystick, no free movement, no off-fractal movement. Every legal
position is generated by the same dynamical system that produces the
Sierpinski triangle. You are not controlling a character *on* a fractal —
you are controlling the rule that *generates* it.

## Play instantly

No build step. No server. No dependencies. No network.

Just open `chaos-engine/index.html` directly in any modern browser
(Chrome, Edge, Firefox, Safari) via `file://` — double-click it.

## Controls

| Input | Action |
|---|---|
| `1` / `2` / `3` | Jump toward attractor 1 / 2 / 3 |
| Arrow keys / WASD | Jump toward the attractor in that direction from YOU |
| Tap attractor button / tap arena | Same single movement path (touch-friendly, 44px+ targets) |
| `H` | Toggle hint route |
| `P` / `Esc` | Pause / resume |
| `M` | Mute |
| `R` | Restart run |

## The game

- **Tutorial** — 7 action-driven steps: meet the particle, choose attractors,
  watch the halfway rule, read the three landing previews, collect, chain
  combos, graduate to Level 1.
- **14 levels** — depths 2 through 7, wave-structured (3–5 waves each),
  untimed early, timed later, with 1–3 star mastery ratings.
- **5 difficulties** — ZEN (no timer, no lives) through INSANE (tiny targets,
  two simultaneous goals). Difficulty changes only pressure —
  collision radius, time, lives, drift, goal count — never the geometry.
  Always 3 attractors, always `r = 0.5`.
- **Endless mode** — depth-8 full gasket, pressure ramps every 4 waves.
- **Daily run** — UTC-date-seeded challenge, same seed for everyone, offline.
- **Coach route** — real beam-search pathfinding (width 8, depth 13,
  terminates inside 0.9R) with a verified address-steered fallback; never a
  fake route. `NO SHORT ROUTE` is shown truthfully if none exists.
- **Scoring** — `100 x combo` (cap x8, 3.2s window), `+60` perfect bonus,
  time bonus on timed levels. Best scores, unlocks, stars, and settings
  persist in guarded `localStorage` (survives corruption/outages via
  in-memory fallback).
- **Accessibility** — keyboard- and touch-playable, shape-coded symbols
  (diamond YOU, triangle GOAL, square NEXT) that work without color,
  SHAPE-ONLY mode, REDUCED EFFECTS + `prefers-reduced-motion` support,
  live-region announcements, visible focus states.
- **Diagnostics** — enable the diagnostics line in Settings; append
  `?debug=1` to run the built-in acceptance self-test in the console.

## Project structure

```
chaos-engine/
├── index.html      # app shell, HUD, canvas, menus, overlays (classic scripts, no modules)
├── css/style.css   # instrument-panel theme, responsive layout
└── js/
    ├── util.js     # PRNG, UTC date seeds, guarded storage, timing
    ├── config.js   # immutable constants + 5 difficulties (pressure only)
    ├── levels.js   # data-driven 14 levels + endless
    ├── ifs.js      # ALL fractal math: movement equation, nodes, beam search
    ├── audio.js    # WebAudio-synthesized SFX, no files
    ├── fx.js       # pooled particles / rings / popups / shake
    ├── input.js    # keyboard + touch, funnels into jump(i)
    ├── render.js   # layered cached canvas renderer (reads state, never mutates)
    └── game.js     # the only state owner: loop, waves, scoring, tutorial, daily
```

## Mathematical notes

- `ifs.js:nextPoint` is the single authoritative movement implementation.
- Goals are generated *on* the fractal (depth-D subdivision nodes and
  forward chaos-game points) — never random screen coordinates.
- `ifs.js:fractalSignature` is byte-identical across difficulties, levels,
  and viewport sizes (unit-triangle geometry only).
- Automated checks cover: exact jump equation, collision radii
  (50px collects on EASY not HARD; 25px collects on HARD), route termination,
  node counts (15…9843), level timing, wave completion, pause freeze, resize
  persistence, and trail expiry. Run them via `window.__chaosEngine.selfTest()`.
